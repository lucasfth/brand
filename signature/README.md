# E-mail signatures

Ready-to-paste hbit signatures for the three mailboxes:

| File | Mailbox |
| --- | --- |
| `hbit-signature-contact.en.html` / `.da.html` | `contact@lucashanson.dk` |
| `hbit-signature-online.en.html` / `.da.html` | `online@lucashanson.dk` |
| `hbit-signature-gmail.en.html` / `.da.html` | `lucastorreshanson@gmail.com` |

Each file holds one standalone signature block (inline-styled table, no external CSS). The mark image loads from the pinned `@v1` jsDelivr URL, so the signature follows the tagged artwork. The en/da pair differs only in the title line (`CTO at EcoRay · Copenhagen` / `CTO hos EcoRay · København`).

## Install

Open the file in a browser, select all, copy, paste into the signature field:

- Mail.app: Settings → Signatures → New Signature, then paste.
- Gmail: Settings → Signature, then paste.

The Space Mono `@import` only affects the local preview; e-mail clients do not load webfonts, so recipients see the signature in their system monospace. The identity is the mark, the beam colours and the layout, not the font.

## Updates

The files are static output, not generated by `scripts/build.py`. When the mailbox set or the title changes, edit the HTML directly, keep all files consistent, and commit.
